## 目标
Windows 平台上将应用全局字体指定为微软雅黑（Microsoft YaHei），其他平台行为不变。

## 改动（仅 1 个文件）
`lib/utils/theme_utils.dart` 的 `getThemeData()`：

1. 新增导入：`import 'package:PiliPlus/utils/platform_utils.dart';`
2. 方法内新增：`final fontFamily = PlatformUtils.isWindows ? 'Microsoft YaHei' : null;`
3. `ThemeData(...)` 构造函数传入 `fontFamily: fontFamily`。

## 生效原理（已核对 Flutter 3.47.1 SDK 源码 theme_data.dart:505-524）
- `ThemeData(fontFamily:)` 会把字体写入默认 textTheme，再与自定义 textTheme 逐样式 merge（未显式设 fontFamily 的样式继承默认字体）。
- 本项目自定义 textTheme 各样式只设 `fontWeight`、未设字体，所以全部文本样式都会继承微软雅黑；`appFontWeight == -1`（默认值，textTheme 为 null）时同样生效。
- `darkenTheme()` 的 `copyWith` 保留 fontFamily，纯黑主题不受影响。

## 覆盖范围与边界
- 明暗两套主题均在 `getThemeData()` 构建（main.dart:256/262），一处改动全覆盖。
- `PlatformUtils.isWindows` 带 `vm:platform-const` 注解，非 Windows 平台编译期裁剪，零开销；`platform_utils.dart` 仅依赖 dart:io，无循环导入。
- 不动的显式字体（有意保留）：标题栏 `Segoe UI`（window_caption.dart:121，模拟 Win11 原生标题栏）、日志/播放器调试 `Monospace`、数字统计 `digital_id_num`。
