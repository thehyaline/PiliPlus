## 目标
设置 → 外观设置 中新增"应用字体"设置项（仅 Windows），选择 HarmonyOS Sans（默认）或系统字体，即时切换全局字体；HarmonyOS Sans 字体文件复制进项目并随 Windows 构建打包。

## 改动清单

### 1. 复制字体文件
- 将 `D:\Downloads\HarmonyOS-Sans\HarmonyOS Sans\HarmonyOS_Sans_SC\` 下的 6 个 TTF（Thin/Light/Regular/Medium/Bold/Black，各约 8MB）复制到 `assets/fonts/`，同时复制 LICENSE.txt 保留许可信息。

### 2. pubspec.yaml 声明字体
在现有 fonts 段追加 family `HarmonyOS Sans SC`，声明全部 6 个字重（100/300/400/500/700/900）。pubspec 声明的字体会自动打进 Windows 构建（Flutter 模板自动安装 flutter_assets，无需改 CMake），且支持与"App字体字重"设置配合使用真实字重。
- 注意：字体段不支持按平台过滤，Android/iOS 构建也会多打包约 48MB（可接受，桌面是主要目标；若介意后续可改为 FontLoader + 平台过滤 assets）。

### 3. 新建枚举 lib/models/common/theme/app_font_type.dart
仿照 theme_type.dart 的写法：
```dart
enum AppFontType {
  harmony('HarmonyOS Sans'),
  system('系统字体');
  final String desc;
  const AppFontType(this.desc);
}
```

### 4. 存储：storage_key.dart + storage_pref.dart
- `SettingBoxKey` 加 `appFontFamily = 'appFontFamily'`（放在 appFontWeight 旁边）。
- `Pref` 加 getter：`AppFontType.values[_setting.get(SettingBoxKey.appFontFamily, defaultValue: 0)]`，默认 0 = HarmonyOS Sans。

### 5. 主题注入：lib/utils/theme_utils.dart
`getThemeData()` 里：
```dart
final fontFamily = PlatformUtils.isWindows && Pref.appFontFamily == AppFontType.harmony
    ? 'HarmonyOS Sans SC' : null;
```
`ThemeData(...)` 传入 `fontFamily: fontFamily`（对明暗两套主题、纯黑主题都生效；仅覆盖未显式指定字体的文本，标题栏 Segoe UI、日志 Monospace、图标字体等不受影响）。需新增 platform_utils 和 app_font_type 的 import。

### 6. 设置项：lib/pages/setting/models/style_settings.dart
在"App字体字重"项（第 99 行）后加 Windows 专属项，并新增处理函数：
```dart
if (PlatformUtils.isWindows)
  NormalModel(
    title: '应用字体',
    leading: const Icon(Icons.font_download_outlined),
    getSubtitle: () => '当前字体：${Pref.appFontFamily.desc}',
    onTap: _showAppFontDialog,
  ),
```
`_showAppFontDialog`：用现有 `SelectDialog<AppFontType>`（与"页面过渡动画"同一弹窗模式），选项显示"HarmonyOS Sans（默认）"和"系统字体"；选中后 `GStorage.setting.put(...)` + `Get.updateMyAppTheme()` + `setState()`，立即生效。所需 import（SelectDialog、Get 扩展、PlatformUtils、GStorage）该文件已具备，仅需加 app_font_type。

## 验证
- `flutter analyze` 无新告警。
- `flutter build windows` 后检查构建产物中 FontManifest.json 包含 HarmonyOS Sans SC 且 6 个 ttf 已随 flutter_assets 打包。
