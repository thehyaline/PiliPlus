## 背景
构建输出中的 CMake 警告（CMP0175）来自 git 依赖插件 flutter_inappwebview_windows v6.1.5 的 `windows/CMakeLists.txt:37`：`add_custom_command(TARGET ... PRE_BUILD ... DEPENDS ${NUGET})` 中 `DEPENDS` 是 TARGET 签名不支持的无效参数（CMake 3.30 弃用、4.0 起移除 OLD 行为，无法用 cmake_policy 压制）。该行实际从不生效，删除无副作用。警告不阻断构建，但会污染输出，且未来 CMake 版本可能升级为错误。

## 改动（仅 1 处）
`build_windows.bat`：在补丁步骤（[2/4]）之后、构建（[3/4]）之前，新增「插件 CMake 兼容性修复」步骤：

- 用 PowerShell 定位 `%LOCALAPPDATA%\Pub\Cache\git\flutter_inappwebview-*\flutter_inappwebview_windows\windows\CMakeLists.txt`
- 若文件含 `DEPENDS ${NUGET}` 行则删除该行并提示「已修复」；已修复过则提示「无需修复」；缓存不存在则跳过
- 幂等：重复运行无副作用；此步骤失败不阻断构建（仅提示后继续）

## 影响说明
- 修改的是 pub 全局缓存中该 git 依赖插件的文件；删除的是从未生效的无效参数行，对使用该插件的所有项目均安全
- git 缓存 resolved-ref 固定，`pub get` 不会覆盖此改动；用户清理 pub cache 后脚本下次运行会自动重新修复
- CI 使用同一插件，若其 CMake 为 4.x 也会出现同样警告（不影响构建）；CI 不走本脚本，暂不动 CI

## 验证
- 本机已有该插件缓存（已确认路径），实测修复命令在真实文件上能正确删除 DEPENDS 行且幂等（测试后恢复原文件，让用户下次跑脚本时由脚本完成修复，同时验证脚本路径）
- bat 保持 CRLF 行尾、语法检查
