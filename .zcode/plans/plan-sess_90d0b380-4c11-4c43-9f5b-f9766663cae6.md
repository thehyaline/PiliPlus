## 动态页选项卡改造方案

### 需求对应
1. 隐藏番剧/专栏/UP 选项卡 → 只保留 全部、视频 两个 tab
2. 投稿选项卡更名为"视频"
3. 点击未选中的 UP 头像：回当前 tab 顶部，并把当前 tab 列表替换为对应 UP 的动态（全部 tab）/投稿（视频 tab）
4. 点击已选中的 UP 头像：回顶并刷新当前 tab 数据；选中"全部动态"时回顶刷新全部动态/全部视频
5. 顶部 tab 居中

### 改动文件（6 个）

**1. `lib/models/common/dynamic/dynamics_type.dart`**
- `video('投稿')` → `video('视频')`
- 新增 `static const visibleValues = [all, video];`（枚举其余成员 pgc/article/up 保留，供数据层/API 兼容）

**2. `lib/pages/dynamics/view.dart`**
- TabBar `tabs:` 与 TabBarView `children:` 改用 `DynamicsTabType.visibleValues`
- TabBar `tabAlignment: .start` → `tabAlignment: .center`（保持 isScrollable: true）

**3. `lib/pages/dynamics/controller.dart`**
- `TabController(length: DynamicsTabType.visibleValues.length)`；`controller` getter 中 tag 查找改为 `DynamicsTabType.visibleValues[tabController.index].name`
- 删除 `_jumpToTab`（不再跳 tab）
- 重写 `onSelectUp`：
  - 已选中（`currentMid == mid`）：`mid == -1` 时先 `singleRefresh()`（顺带刷新 UP 面板），再 `controller?.onReload()`（onReload 自带 jumpToTop，即"回顶+刷新当前 tab"）
  - 未选中：`hostMid = mid; currentMid = mid;` 后 `controller?.onReload()`（当前 tab 列表原地替换为对应 UP 的动态/投稿）
  - 移除原"预刷新 UP tab controller"逻辑

**4. `lib/http/dynamics.dart`** — `followDynamic` 参数逻辑改造：
```dart
final hasUp = hostMid != null && hostMid > 0;
Map<String, dynamic> data = {
  if (hasUp) 'host_mid': hostMid,
  if (type == .video || !hasUp) 'type': type.name,
  'offset': ?offset,
  'features': Constants.dynFeatures,
};
```
即：全部 tab 选中 UP → 只传 `host_mid`（与现在 UP tab 的已验证行为一致）；视频 tab 选中 UP → `host_mid` + `type=video`（UP 的视频类动态，等价于 B 站空间视频流参数）；未选中 UP → 维持现状只传 `type`。

**5. `lib/utils/storage_pref.dart`** — `defaultDynamicTypeIndex` getter 加 `.clamp(0, DynamicsTabType.visibleValues.length - 1)`，防止旧存档里保存了已隐藏 tab 的索引（如 UP=4）导致 TabController 越界崩溃，同时设置页"动态展示"对话框当前值恒有效。

**6. `lib/pages/setting/models/extra_settings.dart`** — `_showDefDynDialog` 的选项列表 `DynamicsTabType.values.take(4)` → `DynamicsTabType.visibleValues`（默认 tab 只能在 全部/视频 中选）。

### 行为说明（无需改动的部分）
- UP 面板（头像列表、全部动态、"我"）及其位置设置不变；选中的 UP 过滤对两个 tab 全局生效（切 tab 后同一 UP 在 全部 显示其动态、在 视频 显示其投稿）
- 下拉刷新、双击导航栏回顶/刷新（`toTopOrRefresh`）均沿用现有链路，自动带当前 hostMid
- `dynamics_tab/controller.dart` 的 `customGetData` 已传 hostMid，无需改动；`onBlock` 中 `!= .up` 判断变为恒真，保留不影响

改完后运行 `dart format`（仅格式化改动文件）与 `flutter analyze`，确认无静态错误。
