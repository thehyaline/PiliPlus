## 修复"相关推荐两列太窄"问题（全局修复）

### 根因
相关视频列表（及所有横向卡片网格）使用 `SliverGridDelegateWithMaxCrossAxisExtent`，列数 = ceil(面板宽 / (smallCardWidth×2))，默认上限 480dp。面板宽度落在 480~960dp 时强行 2 列，卡片仅 240~480dp 宽——而 `VideoCardH` 固定行高 110dp + 16:10 封面（宽 160dp）+ 24dp padding + 10dp 间距后，文字列只剩几十 dp，数据行/菜单按钮被挤掉。

### 改动（仅 1 个文件：`lib/utils/grid.dart`）

1. **给自定义的 `SliverGridDelegateWithMaxCrossAxisExtent` 增加可选 `minCrossAxisExtent` 参数**（double?，默认 null = 不限制）：
   - 构造函数增加参数 + 字段 + assert（非空时 > 0），更新类注释。
   - `getLayout` 中在现有列数计算后追加下限约束：
     ```dart
     if (minCrossAxisExtent != null) {
       crossAxisCount = min(
         crossAxisCount,
         (constraints.crossAxisExtent / (minCrossAxisExtent + crossAxisSpacing)).floor(),
       );
     }
     crossAxisCount = max(1, crossAxisCount);  // 已有
     ```
   - `shouldRelayout` 增加 `minCrossAxisExtent` 的比较。

2. **`Grid.videoCardHDelegate` 传入 `minCrossAxisExtent: 400`**（新增命名常量如 `Grid.videoCardHMinWidth = 400.0`，注释说明来自封面 160 + padding 24 + 间距 10 + 数据行 ~130 + 余量）。

### 效果（默认设置 480 上限时）
- 面板 480~799 → 1 列（卡片 480~799dp，正常显示）——修复用户 Windows 端场景
- 面板 800~1199 → 2 列（卡片 ≥400dp）
- 面板 1200+ → 3 列（与现状一致）
- 播放页侧栏（280~425dp）、手机竖屏等窄面板 → 单列，不受影响
- 宽面板（如 2000dp → 5 列 × 400dp）与现状一致

所有共用 `videoCardHDelegate` 的列表（搜索、收藏、历史、分区、稍后再看等约 40 页）一并受益；设置里"列表宽度（dp）限制 → 其他"滑块仍作为卡片宽度上限生效，语义不变（仍需重启生效，本次不改）。

### 验证
- `flutter analyze lib/utils/grid.dart`（或全量 analyze）确认无编译错误。
- 边界值核对：481 → 1列、800 → 2列、1300 → 3列、425（侧栏）→ 1列。
