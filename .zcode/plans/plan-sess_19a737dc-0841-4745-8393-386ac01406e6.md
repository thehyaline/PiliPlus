在项目根目录创建一个一键同步脚本 `sync_github.bat`（与现有 build_android.bat / build_windows.bat 风格一致：chcp 65001、中文 [信息]/[错误] 输出、goto 错误处理、结尾 pause）。

脚本流程：
1. 检查 git 和 origin 远端是否可用。
2. 自动提交本地改动：`git add -A`，若有改动则提交，提交信息为 `sync: yyyy-MM-dd HH:mm:ss`（时间戳由 PowerShell 生成，避免系统日期格式差异）。
3. 完整镜像推送（一条命令完成）：
   `git push --prune --force origin +refs/heads/*:refs/heads/* +refs/tags/*:refs/tags/*`
   —— 强推本地所有分支（当前只有 main）、删除云端多余分支（dev、dom、material_ui_migration_main）、同步标签（远端多余的标签也会删除）。
4. 失败时输出错误提示（网络/凭据问题等）并返回非零退出码。

创建完成后会运行一次脚本验证端到端可用 —— 这次运行会真正把当前本地改动（含未提交的修改）提交并强制推送到你的 GitHub 仓库，同时删除那三个多余分支，请确认这一点。除此之外不改动任何其他文件。
