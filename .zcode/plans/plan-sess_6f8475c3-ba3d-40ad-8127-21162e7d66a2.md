## 窗口消失 bug 修复方案

### 根因
用户关闭窗口（X）时，因"退出时最小化"+“显示托盘图标”默认开启，`onWindowClose` → `_hide()`（`setOpacity(0.0)` + `hide()`）把窗口透明化并隐藏到托盘，进程常驻。之后再次启动 exe 时，`windows/runner/main.cpp` 的单实例保护 `FindWindow` 找到旧窗口，`ShowWindow(SW_NORMAL)` 恢复了窗口可见性（任务栏出现任务按钮），但**透明度（WS_EX_LAYERED + alpha=0）不会随 ShowWindow 复位** → 窗口完全透明 → “窗口不见了，任务栏可以看到任务”。

### 改动

**1. `windows/runner/main.cpp`（核心修复）**
单实例分支中，在 `ShowWindow(SW_NORMAL)` 前清除 `WS_EX_LAYERED`，使窗口恢复完全不透明：
```cpp
HWND hwnd = ::FindWindow(L"FLUTTER_RUNNER_WIN32_WINDOW", L"piliplus");
if (hwnd != NULL) {
  // 关闭到托盘时窗口被置为透明（setOpacity(0)+hide），ShowWindow(SW_NORMAL)
  // 只恢复可见性不会复位透明度，这里移除 WS_EX_LAYERED 使窗口恢复不透明。
  LONG_PTR ex_style = ::GetWindowLongPtr(hwnd, GWL_EXSTYLE);
  if (ex_style & WS_EX_LAYERED) {
    ::SetWindowLongPtr(hwnd, GWL_EXSTYLE, ex_style & ~WS_EX_LAYERED);
  }
  ::ShowWindow(hwnd, SW_NORMAL);
  ::SetForegroundWindow(hwnd);
  return EXIT_FAILURE;
}
```

**2. `lib/pages/main/view.dart` `_hide()`（防御性加固）**
调换顺序：先 `hide()` 再 `setOpacity(0.0)`。这样任一步失败都不会留下“可见但透明”的窗口（失败时要么窗口仍可见不透明、要么已隐藏）。`_show()` 保持现有“先恢复 opacity 再 show”的顺序，不破坏 window_manager#571 的防闪烁 workaround。

**3. `lib/utils/storage_pref.dart` `windowSize` getter（同症状家族加固）**
增加校验：长度必须为 2 且两值 > 0，否则回退默认 `Size(1280.0, 720.0)`。防止 Hive 中损坏的窗口尺寸导致 `calcWindowBounds` 计算 0 尺寸或抛 RangeError，使 `waitUntilReadyToShow` 回调中断、窗口永不显示（本仓库 runner 已注释掉原生 `this->Show()`，窗口只靠 Dart 侧 `show()` 显示）。

### 验证
- `flutter analyze` 通过
- `flutter run -d windows` 复现路径验证：关闭窗口（X）→ 任务栏按钮消失 → 再次双击 exe → 窗口应正常显示且不透明；托盘图标显示/隐藏切换仍正常
- 注意：改动 1 是原生代码，需要重新构建 Windows runner 才生效
