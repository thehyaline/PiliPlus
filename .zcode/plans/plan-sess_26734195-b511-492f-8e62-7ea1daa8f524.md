## 目标

把 Windows 端原生标题栏替换为 WinUI3 风格的自绘标题栏，给左侧图标+标题加可调内边距，解决大圆角显示器左上角遮挡问题。

## 关键调研结论

- 原生 Win32 标题栏（`WS_OVERLAPPEDWINDOW`）的图标/标题由 DWM 绘制在最左端，位置不可调 → 唯一解法是自绘标题栏。
- 仓库的 window_manager fork（0.5.2）原生侧 `setTitleBarStyle`/`setAsFrameless` 是空操作（与上游一致），所以现有"显示窗口标题栏"设置项开关实际上都显示原生标题栏。
- fork 的 Dart 侧已导出全套现成组件：`WindowCaptionButton`（min/max/unmax/close，Win11 悬停态+关闭按钮红色）、`DragToMoveArea`（拖拽+双击最大化）、`popUpWindowMenu()`（原生系统菜单）、`kWindowCaptionHeight=32`。应用图标 `assets/images/logo/logo.png` 已在 assets 中。
- media_kit 原生全屏是在同一窗口上移除 `WS_OVERLAPPEDWINDOW` 铺满屏幕 → Flutter 内容（含自绘标题栏）在全屏时仍可见，需要显式隐藏；`lib/plugin/pl_player/utils/fullscreen.dart` 是唯一进出全屏入口，画中画（PIP）在 `controller.dart:211-255`。

## 实现方案

### 1. 原生层：窗口创建时移除标题栏（1 行改动）

`windows/runner/win32_window.cpp` 的 `CreateWindow`：样式 `WS_OVERLAPPEDWINDOW` → `WS_OVERLAPPEDWINDOW & ~WS_CAPTION`（保留 WS_THICKFRAME 缩放宽高、WS_SYSMENU 系统菜单、最小化/最大化框、系统阴影、Win11 圆角）。窗口启动即无原生标题栏，无闪烁；`main.cpp` 单实例 FindWindow（类名+标题）不受影响。

### 2. 新建自绘标题栏组件（WinUI3 风格）

新文件 `lib/widgets/window_caption.dart`（应用自定义，不复用 fork 的 WindowCaption 因为它无图标、内边距固定 16 且无隐藏逻辑）：

- 高度 32（`kWindowCaptionHeight`）。
- 布局：Row = [ 左侧留白（默认 32px，核心修复点，常量可调）→ 应用图标 logo.png（16px）→ 标题 `Constants.appName`（跟随主题明暗）→ Expanded 拖拽区（复用 fork 的 `DragToMoveArea`，自带双击最大化）→ 右侧留白（16px，防右侧圆角裁按钮）→ `WindowCaptionButton` 最小化/最大化(还原)/关闭（复用 fork 组件，监听 onWindowMaximize/Unmaximize 切换图标）]。
- 右键空白区 → `windowManager.popUpWindowMenu()`（原生系统菜单：还原/移动/大小/最小化/最大化/关闭）。
- 监听全局 `ValueNotifier<bool>`：原生全屏（media_kit）和桌面画中画时隐藏标题栏（ValueListenableBuilder + AnimatedSwitcher）。

### 3. 挂载到所有路由之上

`lib/main.dart` 的 `_builder`（GetMaterialApp builder，MediaQuery/uiScale 包装内部）：`PlatformUtils.isWindows && Pref.showWindowTitleBar` 时包一层 `Column [ WindowCaption, Expanded(child) ]`。

- 所有路由（主界面、视频页、直播页）都显示标题栏，与原生标题栏行为一致。
- 页面布局零改动：内容起始位置与现在（原生标题栏时）完全相同。
- 智能弹窗等 overlay 在标题栏之上，不冲突。
- `WindowOptions.titleBarStyle` 字段删除（原生已无标题栏，无意义）。

### 4. 全屏/画中画隐藏

- `fullscreen.dart`：新增全局 `ValueNotifier<bool> desktopCaptionHidden`（或类似），`enterDesktopFullScreen`/`exitDesktopFullScreen` 内设置。
- `controller.dart`：`enterDesktopPip`/`exitDesktopPip` 中删除 `setTitleBarStyle` 调用（fork 里本就是空操作），改为设置/复位该 notifier。

### 5. 设置项语义

保留 `Pref.showWindowTitleBar`（默认 true，needReboot 语义不变），含义变为"显示自定义标题栏"；关闭时无标题栏（与设置原意一致）。`style_settings.dart` 文案可不改。

## 已知取舍

- 最大化按钮悬停不再弹出 Win11 快照布局浮层（自绘按钮无法触发原生浮层）；Win+Z 快捷键、拖拽到屏幕边缘贴边仍可用。
- 左侧留白 32px 为默认值（常量），如你的显示器圆角更大可在实施时调整或后续做成设置项。

## 验证

1. `build_windows.bat`（仓库现有构建脚本，会先跑 patch.ps1）构建 Windows 版本。
2. 运行验证：无原生标题栏、自绘栏正常显示（图标+标题+按钮）、拖拽移动、双击最大化/还原、三个按钮功能、右键系统菜单、播放视频进全屏标题栏隐藏、画中画模式标题栏隐藏、退出后恢复、Win+Z/边缘贴边仍可用。
3. 圆角遮挡效果需你在自己显示器上最终确认，留白常量可调。
