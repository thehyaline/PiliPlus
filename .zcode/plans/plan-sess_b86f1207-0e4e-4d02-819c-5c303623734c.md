## 目标

统一搜索页与搜索结果页顶部的搜索框样式,与首页假搜索框(`lib/pages/home/view.dart` 的 `searchBar()`)视觉一致:
- 圆角矩形背景:圆角 25,背景色 `colorScheme.onSecondaryContainer.withValues(alpha: 0.05)`(较浅的主题派生色,明暗模式自适应)
- 最小/最大宽度:`ConstrainedBox(minWidth: 200, maxWidth: 500)`,搜索框在 AppBar 中水平居中
- 搜索页的清空、搜索按钮移入背景色内,置于输入框右侧;搜索结果页为按钮,无额外按钮

## 修改 1:搜索页 `lib/pages/search/view.dart`(第 92-136 行 `_buildAppBar`)

**actions**:移除清空按钮和搜索按钮,仅保留 UID 按钮(第 100-110 行 Obx 逻辑不变)。当 UID 按钮不显示时,用 `SizedBox(width: 48)` 占位,使 actions 与 leading 返回按钮(56)基本等宽,保证搜索框真正居中。

**title** 改为:
```
Center(
  child: ConstrainedBox(
    constraints: const BoxConstraints(minWidth: 200, maxWidth: 500),
    child: SizedBox(
      height: 44,   // 与首页搜索框一致
      child: Material(
        borderRadius: BorderRadius.circular(25),
        color: colorScheme.onSecondaryContainer.withValues(alpha: 0.05),
        child: Row(children: [
          Expanded(child: TextField(...)),  // 保留原有属性
          IconButton(清空, onPressed: onClear),
          IconButton(搜索, onPressed: submit),
          SizedBox(width: 10),
        ]),
      ),
    ),
  ),
)
```
- TextField 保留:autofocus、focusNode、controller、textInputAction.search、onChanged、onSubmitted;decoration 增加 `isDense: true`、`contentPadding: EdgeInsets.symmetric(horizontal: 16)`、`textAlignVertical: TextAlignVertical.center`,适配 44 高度
- 清空/搜索 IconButton 保留原 tooltip、图标(clear/search, size 22)和回调,加 `style: Style.buttonStyle`(已存在于 `lib/common/style.dart`)压缩点击尺寸适配 44 高度;需要补充 `import 'package:PiliPlus/common/style.dart';`
- AppBar 加 `titleSpacing: 0`,避免 title 默认间距挤压搜索框宽度导致 minWidth 溢出

## 修改 2:搜索结果页 `lib/pages/search_result/view.dart`(第 80-108 行)

**title** 改为:Center > ConstrainedBox(同样 min 200 / max 500)> SizedBox(height 44)> Material(圆角 25 + 同上浅色背景)> GestureDetector(保留原点击逻辑:`_isFromSearch ? Get.back() : Get.offNamed('/search', ...)`,`HitTestBehavior.opaque`)> Row:
- 左侧搜索图标(`Icons.search_outlined`, size 20, 颜色 outline),与首页搜索框一致
- 关键词文本(`maxLines: 1, overflow: ellipsis`,颜色用 `onSurface`),Expanded 撑满
- 左内边距约 14,与首页一致

**actions**:加 `SizedBox(width: 56)` 占位,与 leading 返回按钮等宽,使搜索框居中。

## 不改动的内容

- 两个页面的 controller 逻辑(清空行为、submit、UID 跳转、点击回搜索页)全部保留
- AppBar 底部细分隔线、SimpleScaffold 结构不变

## 验证

`flutter analyze` 检查两个修改文件无错误;数值(minWidth/maxWidth/高度/圆角)可在实现后按视觉效果微调。
