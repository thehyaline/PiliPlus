## 目标

将视频播放器、直播播放器底部控制栏上的"画面比例"按钮移除，改为在各自的"更多"菜单中以列表项（标题"画面比例"、副标题"当前比例 XXX"）进入，点击后弹出与"选择画质"页面同款的面板来选择比例。仅改动 UI/交互，切换逻辑继续复用现有的 `plPlayerController.toggleVideoFit()`，播放器功能逻辑一律不动。

## 改动一：视频播放器

**1. `lib/plugin/pl_player/view/view.dart`（移除底部栏按钮）**
- 删除 603-640 行 `BottomControlType.fit =>` 分支（画面比例 PopupMenuButton）。
- 删除 915 行 `if (flag) .fit,`（按钮显示条件）。
- 删除第 46 行 `import .../video_fit_type.dart`（grep 确认该文件中此 import 仅被被删代码使用）。

**2. `lib/pages/video/widgets/header_control.dart`（更多设置菜单）**
- 新增 import `package:PiliPlus/plugin/pl_player/models/video_fit_type.dart`。
- 在"解码格式" ListTile（635-647 行）之后、"播放顺序"之前插入"画面比例" ListTile：
  - `leading: Icon(Icons.aspect_ratio)`，`title: '画面比例'`，`subtitle: Obx(() => Text('当前比例 ${plPlayerController.videoFit.value.desc}'))`（videoFit 是 Rx，用 Obx 保证实时更新）。
  - `onTap: Get.back() + showSetVideoFit()`。
  - 放在 `if (!isFileSource)` 块之外（紧跟其后），保持画面比例对文件源也可用的原有行为。
- 新增方法 `showSetVideoFit()`，样式完全仿照 `showSetDecodeFormats()`（1083-1150 行）：
  - `showBottomSheet` 弹出面板，圆角 Material + 顶部标题"画面比例" + `SliverList.builder` 遍历 `VideoFitType.values`（拉伸/自动/裁剪/等宽/等高/原始/限制/4:3/16:9）。
  - 当前选中项 trailing 显示 `Icons.done`（主色），点击后 `Get.back()` + `plPlayerController.toggleVideoFit(boxFit)` + `SmartDialog.showToast("画面比例已变为：${boxFit.desc}")`（与选择画质页面的反馈一致）。

## 改动二：直播播放器

**1. `lib/pages/live_room/widgets/bottom_control.dart`（移除底部栏按钮）**
- 删除 130-162 行的画面比例 PopupMenuButton。
- 删除第 5 行 import `video_fit_type.dart`（grep 确认仅被删代码使用）。

**2. `lib/pages/live_room/widgets/header_control.dart`（更多菜单）**
- 新增 import `video_fit_type.dart`。
- 在"切换路线" PopupMenuItem（253-263 行）之后插入"画面比例" PopupMenuItem：
  - 两行布局：第一行 `Icons.aspect_ratio` + "画面比例"；第二行副标题"当前比例 XXX"（Obx 包裹，小号灰色字体）。
- 新增方法 `showSetVideoFit()`，与该文件 `_showLiveStreamDialog` 同风格的 `showModalBottomSheet`（useSafeArea、圆角 Material、顶部标题"画面比例" + ListView 列出 `VideoFitType.values`），当前项 trailing `Icons.done`，点击后 `Get.back()` + `toggleVideoFit(boxFit)` + toast（与视频侧一致）。

## 不改动的内容

- `PlPlayerController.toggleVideoFit()` / `_initVideoFit()`（controller.dart）及渲染层 FittedBox/aspectRatio 应用逻辑——功能逻辑不变。
- `VideoFitType` 枚举、`BottomControlType` 枚举定义本身。
- 画质、解码格式、切换线路等其余选项。
