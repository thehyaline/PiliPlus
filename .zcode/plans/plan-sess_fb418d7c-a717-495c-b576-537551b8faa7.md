## 实现计划：动态页"正在直播板块"

### 需求要点
在动态页新增一个不随动态列表滚动的"正在直播板块"（大屏 width>800 时、设置选择左/右侧时显示），数据复用动态页 up 面板已有的 `liveUsers` 数据，跟随整体刷新；同时隐藏 up 面板中原有的 Live 列表及展开按钮。

### 一、新增枚举与存储（3 个文件）

1. **新建 `lib/models/common/dynamic/live_panel_position.dart`**（参照 `up_panel_position.dart`）：
   ```dart
   enum LivePanelPosition {
     left('左侧'), right('右侧'), hidden('不显示');
     const LivePanelPosition(this.label);
     final String label;
   }
   ```
   默认 `left`。

2. **`lib/utils/storage_key.dart`**：`SettingBoxKey` 中 `upPanelPosition`（225 行）附近新增 `livePanelPosition = 'livePanelPosition'`。

3. **`lib/utils/storage_pref.dart`**：新增 getter（仿 194-199 行 `upPanelPosition`）：
   ```dart
   static LivePanelPosition get livePanelPosition =>
       LivePanelPosition.values[_setting.get(
         SettingBoxKey.livePanelPosition,
         defaultValue: LivePanelPosition.left.index,
       )];
   ```

### 二、设置页 `lib/pages/setting/models/style_settings.dart`

1. **标题去重**（268-306 行"动态页"组）：去掉标题中重复的"动态/动态页"字样：
   - `动态页启用瀑布流` → `启用瀑布流`
   - `动态页UP主显示位置` → `UP主显示位置`
   - `动态页显示所有已关注UP主` → `显示所有已关注UP主`
   - `动态页展开正在直播UP列表` → `展开正在直播UP列表`
   - `动态未读标记` → `未读标记`

2. **新增设置项**（放在"展开正在直播UP列表"之后、"动态未读标记"之前）：
   ```dart
   NormalModel(
     title: '正在直播板块',
     leading: const Icon(Icons.live_tv),
     getSubtitle: () => '当前板块位置：${Pref.livePanelPosition.label}（仅在大屏设备生效）',
     onTap: _showLivePanelPosDialog,
   ),
   ```

3. **新增对话框 `_showLivePanelPosDialog`**（仿 790-807 行 `_showUpPosDialog`，用 `SelectDialog<LivePanelPosition>` 三选一），写入后**热生效**（不提示重启）：
   ```dart
   await GStorage.setting.put(SettingBoxKey.livePanelPosition, res.index);
   if (Get.isRegistered<DynamicsController>()) {
     Get.find<DynamicsController>().livePanelPosition.value = res;
   }
   SmartDialog.showToast('设置成功');
   setState();
   ```
   需新增 import：`live_panel_position.dart`、`pages/dynamics/controller.dart`。

### 三、控制器热生效 `lib/pages/dynamics/controller.dart`

- `final upPanelPosition = Pref.upPanelPosition;`（33 行）保持不变；
- 新增 `final livePanelPosition = Pref.livePanelPosition.obs;`（Rx，供设置页热更新 + 动态页 Obx 监听）。

### 四、动态页布局 `lib/pages/dynamics/view.dart`

1. **新增 `livePanelPart(theme)`**：`Obx` 包裹，读取 `livePanelPosition.value` 与 `loadingState.value`，渲染新组件 `LivePanel`（见第五节）。板块宽约 300，撑满高度，内部独立滚动（不随动态列表滚动）。

2. **大屏判定**：`context.showNavbar`（即 `MediaQuery.width > 800`）。`bool get showLivePanel => controller.livePanelPosition.value != LivePanelPosition.hidden && context.showNavbar;`（在 State 中，`context` 可用）。

3. **布局组合**（build 内，132-165 行 switch 基础上叠加）：
   - 先计算 `Widget? liveLeft = showLivePanel && pos == .left ? livePanelPart(theme) : null;` 及 `liveRight` 同理（用项目已有的 `?liveLeft` null-aware element 语法，见 175 行 `?leading`）。
   - `top`：`Row[liveLeft?, Expanded(Column[upPanelPart, Expanded(child)]), liveRight?]`
   - `leftFixed`：`Row[liveLeft?, upPanelPart, Expanded(child), liveRight?]`（直播板块在 up 面板外侧）
   - `rightFixed`：`Row[liveLeft?, Expanded(child), upPanelPart, liveRight?]`
   - `leftDrawer/rightDrawer`：`Row[liveLeft?, Expanded(child), liveRight?]`（drawer 不受影响）

4. **UpPanel 传参**：`upPanelPart` 将 `showLiveSection: !showLivePanel` 传入 `UpPanel`，并在 `Obx(() => _buildUpPanel(...))` 内计算，实现热生效。

### 五、新组件 `lib/pages/dynamics/widgets/live_panel.dart`

`LivePanel`（StatelessWidget，接收 `upData: FollowUpModel` + `dynamicsController`）：

1. **圆角背景**：Container + `BoxDecoration(color: theme.colorScheme.primaryContainer, borderRadius: 12)`（取主题动态色，随主题/动态取色自动变化），margin 内边距。

2. **标题栏**（整栏 `InkWell`，onTap → `Get.to(const LiveFollowPage())`）：
   - 左侧 `Text('正在直播')`（primary 色）；
   - 右侧 `moreTextButton(onTap: 同上跳转)`（`lib/common/widgets/button/more_btn.dart`，自带"查看更多 >"符号，与首页直播 tab 一致）。

3. **列表**：`Expanded(ListView.builder)`，数据 `upData.liveUsers?.items`（`List<LiveUserItem>`，随动态页 `singleRefresh` → `followUp()` 自动刷新，满足"跟随整体刷新"；无数据时显示"暂无正在直播的UP主"占位提示）。每行：
   - 左侧头像：`NetworkImgLayer(type: .avatar, src: item.face)`（38px）+ 右上角 `Badge(label: Text(' Live '))`（复制 `up_panel.dart` 170-186 行的写法）；
   - 右侧两行：主标题 `item.uname`、副标题 `item.title`（单行省略，outline 色）；
   - onTap → `feedBack(); PageUtils.toLiveRoom(item.roomId)`。

### 六、UpPanel 隐藏 Live 部分 `lib/pages/dynamics/widgets/up_panel.dart`

- 新增字段 `final bool showLiveSection;`（构造传入）；
- `build` 中：`SliverToBoxAdapter`（Live 展开/收起头部按钮）与 `if (controller.showLiveUp && liveList... ) SliverList.builder`（Live 列表）均改为 `if (widget.showLiveSection) ...` 条件渲染。
- 其余（全部动态、我、已关注 up 列表）保持不变。

### 七、验证

- 运行 `flutter analyze` 确保无语法/静态错误；
- 手工验证项（用户侧）：设置选择后立即生效；大屏（>800 宽）显示板块、小屏不显示；板块不随列表滚动；up 面板中 Live 部分消失；点标题/查看更多进 LiveFollowPage；点行进直播间；下拉刷新后板块数据更新。
