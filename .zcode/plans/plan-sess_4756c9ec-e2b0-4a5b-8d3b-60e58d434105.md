## 修复 Android 应用图标灰色背景

**根因**：`values-v31/colors.xml` 和 `values-night-v31/colors.xml` 在 Android 12+（API 31+）上把图标背景色覆盖成了系统动态色（浅色模式 `system_accent1_100`、深色模式 `system_neutral1_800`），看起来就是灰色。基础文件 `values/colors.xml` 现在已是 `#FF4F88` 背景 / `#FFFFFF` 前景（无需改动），前景 drawable 也已是白色。

**改动**（共 2 个文件、4 行）：

1. `android/app/src/main/res/values-v31/colors.xml`
   - `ic_launcher_background`: `@android:color/system_accent1_100` → `#FF4F88`
   - `ic_launcher_foreground`: `@android:color/system_neutral2_700` → `#FFFFFF`

2. `android/app/src/main/res/values-night-v31/colors.xml`
   - `ic_launcher_background`: `@android:color/system_neutral1_800` → `#FF4F88`
   - `ic_launcher_foreground`: `@android:color/system_accent1_100` → `#FFFFFF`

**不改的部分**：
- `drawable/ic_launcher_foreground.xml` 前景已是白色 `#FFFFFF`，无需改
- `drawable/ic_launcher_background.xml`（粉色矢量）与 `mipmap-*/ic_launcher.png`（minSdk=24 时 API 24-25 用的 logo 位图）不是灰色来源，保持不动，避免用 flutter_launcher_icons 重新生成导致其他图标文件被覆盖

**效果**：所有 Android 版本（API 24+）图标统一为粉色 #FF4F88 背景 + 白色 logo。

**验证**：可选运行 `flutter build apk --debug`（或打包脚本）确认资源编译通过。
