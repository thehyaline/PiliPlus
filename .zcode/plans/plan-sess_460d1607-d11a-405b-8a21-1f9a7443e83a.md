## 功能：新增"中间滑动全屏模式"选项 + 播放器设置分组整理

### Part 1：新增"中间滑动全屏模式"（仅 Windows）

**1. 枚举重命名（共用同一组选项，弹出菜单保持一致）**
- 将 `lib/plugin/pl_player/models/double_click_fullscreen_mode.dart` 重命名为 `desktop_fullscreen_mode.dart`，枚举 `DoubleClickFullScreenMode` 更名为 `DesktopFullScreenMode`（双击与滑动共用，选项仍为 `fullscreen('全屏（默认）')` / `windowFullscreen('窗口全屏')`）。
- 同步更新引用：`play_settings.dart`（import + 2 处）、`storage_pref.dart`（import + getter 类型）、`view.dart`（import + 双击处理）。

**2. `lib/utils/storage_key.dart`**：新增键 `slideFullScreenMode = 'slideFullScreenMode'`。

**3. `lib/utils/storage_pref.dart`**：新增 getter（默认"全屏"）：
```dart
static DesktopFullScreenMode get slideFullScreenMode =>
    DesktopFullScreenMode.values[_setting.get(
      SettingBoxKey.slideFullScreenMode,
      defaultValue: DesktopFullScreenMode.fullscreen.index,
    )];
```

**4. `lib/pages/setting/models/play_settings.dart`**：在"鼠标双击全屏模式"之后新增（仅 Windows 显示）：
```dart
if (PlatformUtils.isWindows)
  NormalModel(
    title: '中间滑动全屏模式',
    leading: const Icon(Icons.swipe_up_outlined),
    getSubtitle: () => '当前滑动全屏模式：${Pref.slideFullScreenMode.desc}',
    onTap: _showSlideFullScreenModeDialog,
  ),
```
并新增 `_showSlideFullScreenModeDialog`（与 `_showDoubleClickFullScreenModeDialog` 完全同构，存 `SettingBoxKey.slideFullScreenMode`，复用通用 `SelectDialog` 弹出菜单）。

**5. `lib/plugin/pl_player/view/view.dart`**：中间滑动全屏入口（`_onPanUpdate` 中 `_gestureType == .center` 分支的 `fullScreenTrigger`，约 1110-1133 行）：
```dart
void fullScreenTrigger(bool status) {
  plPlayerController.triggerFullScreen(
    status: status,
    inAppFullScreen: PlatformUtils.isWindows &&
        Pref.slideFullScreenMode == DesktopFullScreenMode.windowFullscreen,
  );
}
```
进入/退出全屏都走此函数，天然对称；移动端行为不变。

### Part 2：播放器设置分组整理 + 分割线

**6. `lib/pages/setting/models/model.dart`** 新增分割线模型（material_ui 已导出 Divider）：
```dart
class DividerModel extends SettingsModel {
  const DividerModel();

  @override
  String? get effectiveSubtitle => null;
  @override
  String get effectiveTitle => '';
  @override
  String? get title => null;

  @override
  Widget get widget =>
      const Divider(height: 16, indent: 16, endIndent: 16);
}
```

**7. 重排 `playSettings` 为 8 组，组间插入 `const DividerModel()`**（保留全部 37 项及平台条件，不增删任何选项）：
1. **播放**：自动播放、倍速设置、播放顺序
2. **弹幕/字幕**：弹幕开关、启用点击弹幕(移动)、自动启用字幕
3. **全屏**：默认全屏方向、鼠标双击全屏模式(Win)、中间滑动全屏模式(Win)、中间滑动进入/退出全屏、全屏手势反向、自动全屏、自动退出全屏、全屏显示锁定按钮、全屏显示截图按钮、全屏显示电池电量、全屏展示点赞/投币/收藏等操作按钮、竖屏扩大展示
4. **手势**：双击快退/快进、双击快进/快退时长、滑动快进/快退使用相对时长、滑动快进/快退时长
5. **音量/亮度**：播放器音量(移动)/最高音量(桌面)、左右侧滑动调节亮度/音量、调节系统亮度(Android)
6. **SuperChat**：SuperChat 显示类型、全屏 SC 大小
7. **界面/系统**：底部进度条展示、观看人数、延长播放控件显示时间、启用键盘控制、最小化时暂停/还原时播放(桌面)、倾斜角度阈值(Android)
8. **后台播放**：后台音频服务(移动)、后台播放(移动)、后台画中画(Android)、画中画不加载弹幕(Android)
9. **其他**：播放器设置仅对当前生效

注意：第 8 组全为移动端项，其前导分割线用 `if (PlatformUtils.isMobile) const DividerModel()` 包裹，避免桌面端出现"空组 + 连续两条分割线"。
