## 替换窗口全屏按钮图标

把窗口全屏按钮的图标从 `Icons.aspect_ratio` 换成 `Icons.open_in_full`（四角外扩箭头，视觉重量与全屏按钮的 `Icons.fullscreen` 一致），保持 `size: 24`、`color: Colors.white` 不变。

### 修改位置（共 2 处，图标一致化）

1. **PL Player 播放器控制栏** — `lib/plugin/pl_player/view/view.dart:882`
   ```dart
   icon: const Icon(Icons.aspect_ratio, size: 24, color: Colors.white),
   ```
   改为：
   ```dart
   icon: const Icon(Icons.open_in_full, size: 24, color: Colors.white),
   ```

2. **直播间播放器控制栏** — `lib/pages/live_room/widgets/bottom_control.dart:204`
   ```dart
   icon: const Icon(
     Icons.aspect_ratio,
     size: 24,
     color: Colors.white,
   ),
   ```
   改为：
   ```dart
   icon: const Icon(
     Icons.open_in_full,
     size: 24,
     color: Colors.white,
   ),
   ```

### 说明
- `Icons.open_in_full` 是 Material 内置图标，Flutter 3.47.1 可用（项目设置页 `play_settings.dart:175` 已在使用），无需新增资源或修改 pubspec。
- 不涉及其他文件，无构建配置变更。
