## 生成 Android 签名密钥库并配置签名

你的项目已具备签名读取逻辑（`android/app/build.gradle.kts` 读 `android/key.properties`），`.gitignore` 也已忽略密钥文件，只差生成密钥库和配置文件。

### 执行步骤

1. **定位 keytool**：依次检查 `PATH` 中的 keytool、`JAVA_HOME`、Android Studio 自带的 `jbr\bin\keytool.exe`（`C:\Program Files\Android\Android Studio\jbr\bin\`），找到可用的那个。

2. **生成随机强密码**：用 `openssl rand`（或 PowerShell）生成一个 20 位左右的字母数字密码，作为密钥库口令（keyPassword 与 storePassword 相同，PKCS12 默认如此）。

3. **运行 keytool 生成密钥库**（非交互式，在项目根目录 `E:\Repo\PiliPlus`）：
   ```
   keytool -genkeypair -v -keystore android/app/key.jks -keyalg RSA -keysize 2048 -validity 10000 -alias piliplus -storepass <密码> -keypass <密码> -dname "CN=PiliPlus, O=thehyaline, C=CN"
   ```

4. **验证**：`keytool -list -v -keystore android/app/key.jks` 确认密钥和别名 `piliplus` 生成成功。

5. **创建 `android/key.properties`**：
   ```
   storePassword=<密码>
   keyPassword=<密码>
   keyAlias=piliplus
   storeFile=key.jks
   ```

6. **告知你密码**：把生成的密码在回复中展示给你，你需要自己备份（密钥库和密码丢失后将无法再更新已发布的应用）。如有需要可顺带跑一次 `flutter build apk --release --dart-define...` 验证（此项可选，默认不跑，除非你要求）。

### 不做的事
- 不提交任何密钥文件到 git（`.gitignore` 已覆盖）。
- 不改动 `build.gradle.kts`（现有配置已够用）。
