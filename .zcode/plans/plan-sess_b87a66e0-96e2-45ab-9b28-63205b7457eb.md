修复 flutter pub get 失败导致的 material_ui 补丁链路问题。

## 诊断
- pubspec.yaml:24 `flutter: 3.47.0` 是精确版本约束，本机 SDK 是 3.47.1（D:\Programs\flutter，.fvmrc 也是 3.47.1）→ flutter pub get 报 "Try using the Flutter SDK version: 3.47.0" 失败
- patch.ps1 android 分支（已修复路径问题）在 pub 缓存找不到已应用 android 补丁的 material_ui（缓存里的 material_ui 只有 windows 补丁，android 补丁集多 bottom_sheet_android.patch）→ 删除并重新 pub get → pub get 因 SDK 约束失败 → throw
- build_windows.bat 之前成功是因为 --no-pub 绕过 pub get 且补丁已在缓存

## 修复步骤
1. 修改 pubspec.yaml：`flutter: 3.47.0` → `flutter: 3.47.1`（与 .fvmrc 及本机 SDK 对齐；CI 的 flutter-version-file 随之装 3.47.1，与本地统一）
2. 运行 `flutter pub get`（会更新 pubspec.lock 的 sdks 段、下载 material_ui 到 %LOCALAPPDATA%\Pub\Cache）——验证依赖解析成功
3. 用户重新运行 build_android.bat：patch.ps1 找到 material_ui → 应用 android 补丁集 → 构建 APK

## 验证
- `flutter pub get` 成功且缓存中出现 material_ui-1.0.0 目录
- 模拟运行 build_android.bat 确认补丁步骤不再触发重下（或由用户实际运行确认）
