## 目标

让动态页 UP 列表的"全部动态"按钮跟随程序主题色：背景用当前主题色（含 Android 动态取色），背景过浅时前景 logo 自动改用主题色系中较深的颜色以保证可读。

## 改动 1：`lib/common/widgets/live_tag.dart` — 提取浅色判定为公共函数

把 `LiveTag.build` 里现有的浅色/近灰判定（live_tag.dart:35-37）提取为公共函数，供本文件与 up_panel 复用（行为完全不变，`LiveTag` 改为调用它）：

```dart
/// 背景色过浅或近无彩色时是否应改用深色前景
bool themeColorNeedsDarkFg(Color bg) {
  final lum = bg.computeLuminance();
  return lum > 0.4 || (_isNearGrey(bg) && lum > 0.25);
}
```

## 改动 2：`lib/pages/dynamics/widgets/up_panel.dart` — 按钮跟随主题色

`upItemBuild` 的 `isAll` 分支（152-166 行），将硬编码改为：

```dart
if (isAll) {
  final bg = currentThemeColor();
  avatar = DecoratedBox(
    decoration: BoxDecoration(shape: .circle, color: bg),
    child: Image.asset(
      width: 38,
      height: 38,
      cacheWidth: 38.cacheSize(context),
      Assets.logo2,
      // 主题色过浅/近灰时，前景改用加深的主题色保证可读
      color: themeColorNeedsDarkFg(bg) ? bg.darken(0.5) : Colors.white,
    ),
  );
}
```

要点：
- 背景色用 `currentThemeColor()`（live_tag.dart:7-12）：与同文件直播头像描边（up_panel.dart:182）一致；Android 动态取色开启时取 colorScheme.primary，否则取用户设置的主题色。
- 前景判定复用 `LiveTag` 同一套亮度阈值（`lum > 0.4 || 近灰 && lum > 0.25`）：多数预设色（默认绿、粉、红、蓝等）仍为白色 logo（现状不变）；黄、琥珀、酸橙、浅绿、灰这类浅色/近灰色自动切到 `bg.darken(0.5)` —— 保留主题色色相（hue）的加深色，对最浅的黄色对比度也 ≥3:1。
- 移除 `const BoxDecoration`，新增 `import 'package:PiliPlus/utils/extension/theme_ext.dart';`（`darken` 扩展所在）。
- 选中态逻辑（`isCurrent`/透明度/文字色）不受影响。

## 不改动

- `save_panel/view.dart:510` 的另一处 `Assets.logo2`：那里用的是 `theme.colorScheme.onSurfaceVariant` 且无主题色背景，不在本次范围。
- `LiveTag` 行为保持不变（黑色前景仍为 black87，本次只新增函数、不改其逻辑）。
