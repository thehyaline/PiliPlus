## 修复 Android 构建报错（AAPT resource linking failed）

### 根因
`android/app/src/main/res/drawable/ic_launcher_foreground.xml` 第 9 行和第 14 行的 `android:fillColor` 属性值为 `#@color/ic_launcher_foreground`，`#` 前缀导致 AAPT 无法解析（`#` 后应为十六进制颜色值，资源引用应为 `@color/...`）。

### 修复步骤
编辑 `E:\Repo\PiliPlus\android\app\src\main\res\drawable\ic_launcher_foreground.xml`，将两处（第 9、14 行）的：

```
android:fillColor="#@color/ic_launcher_foreground"
```

改为：

```
android:fillColor="@color/ic_launcher_foreground"
```

### 验证
- 运行 `build_android.bat`（或 `flutter build apk --release`）确认构建通过
- 无需改动其他文件：`@color/ic_launcher_foreground` 资源已在 `values/colors.xml`、`values-v31/colors.xml`、`values-night-v31/colors.xml` 中定义，自适应图标配置 `mipmap-anydpi-v26/ic_launcher.xml` 引用正常
