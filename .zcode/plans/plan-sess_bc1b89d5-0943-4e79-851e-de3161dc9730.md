## 合并上游 2.1.2 到本地 main

### 背景
本地 main 已包含上游全部历史（已合并 2.1.1.2，merge-base = edd60d635）。上游 2.1.2（2026-08-24 发布）共 10 个提交、改动 20 个文件。本地在 14 个文件上有自研改动（设置页分组重构、动态页自定义、包名重构等）。工作区当前干净。

### 步骤

**1. 拉取与合并**
- `git fetch upstream`（获取 2.1.2 tag 和 upstream/main）
- `git merge upstream/main` 创建合并（与历史中 "Merge: 合并上游 2.1.x" 的模式一致）

**2. 解决冲突（按用户决策：字体功能完全采用上游，删除本地自研字体实现）**

高冲突区（手工合并，把上游新功能合入本地重构结构）：
- `lib/pages/setting/models/extra_settings.dart` — 本地分组重构 vs 上游新增"二级评论展示"设置项 + `_showReply2SortDialog`
- `lib/pages/setting/models/style_settings.dart` — 本地重构 vs 上游字体设置入口；删除本地 AppFontType 导入和字号设置项，改用上游 `/fontSetting` 入口
- `lib/pages/setting/models/video_settings.dart` — 本地重构 vs 上游"Wi-Fi/蜂窝网络独立默认解码格式"（#2571）
- `lib/pages/setting/view.dart` — 本地重构 vs 上游字体设置页接入
- `lib/pages/main/controller.dart`、`lib/pages/main/view.dart` — 本地动态页改动 vs 上游 #2636/#2666（退出登录选中账号）/#2537（macOS Cmd+R）
- `lib/pages/dynamics/controller.dart` — 两边都改

字体功能（完全采用上游）：
- `lib/utils/font_utils.dart` — add/add 冲突：直接采用上游版本（枚举系统字体），丢弃本地 HarmonyOS 注册类
- `lib/utils/fontconfig.g.dart`、`lib/pages/setting/pages/font_setting.dart` — 上游新增，采用
- `lib/pages/setting/pages/font_size_select.dart` — 上游删除，接受删除；本地 `style_settings.dart` 的 `/fontSizeSetting` 入口改为 `/fontSetting`
- `lib/utils/storage_key.dart` — 删除本地 `appFontFamily` key；保留本地其他 key（dynamicCardWidth、dynamicsColumnLimit、livePanelPosition、doubleClickFullScreenMode、slideFullScreenMode），合并上游新增 key（appFont、reply2SortType、蜂窝 codec 等）
- `lib/utils/storage_pref.dart` — 删除本地 `appFontFamily` getter 与 AppFontType 导入，其余两边新增合并
- `lib/utils/theme_utils.dart` — 删除本地 HarmonyOS 字体应用逻辑（isWindows && appFontFamily==harmony），保留其他本地改动

Android 层（上游 fontFamilies() JNI 是字体功能的一部分，必须移植）：
- `android/.../com/example/piliplus/AndroidHelper.java` — 上游修改旧路径文件，本地已重命名到 `com/thehyaline/piliplus/`。若 git 未自动识别 rename+modify，手动把上游新增的 `fontFamilies()` 方法移植到新路径文件
- `lib/utils/android/bindings.g.dart` — 合并上游 fontFamilies 绑定与本地包名改动

低风险/自动合并：
- `lib/pages/video/controller.dart`（上游 fix #2621/#2664，本地仅删 1 行）
- `lib/pages/webdav/webdav.dart`、`lib/pages/video/reply_reply/controller.dart`、`lib/router/app_pages.dart` — 本地无改动，自动合并

**3. 验证（不构建）**
- `git diff --check` 检查空白错误
- grep 确认无残留引用：`font_size_select`、`appFontFamily`、`AppFontType`、`loadHarmonyOSFonts`、`FontUtils`（应只剩上游实现）
- `git status` 确认无未解决冲突
- 查看合并后完整 diff 概况向用户汇报

**4. 收尾**
- 创建 merge commit（信息如 "Merge: 合并上游 2.1.2"），不推送、不构建，由用户自行构建验证
